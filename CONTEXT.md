# Wukong Imager

Программа для Windows и Linux, которая записывает образ на SD-карту платы Wukong Pi Zero и заранее готовит настройки первого включения.

## Язык

**Настройки**:
Заполненные поля, которые плата применит сама при первом включении. Незаполненное не меняется.
_Избегать_: конфиг, пресет, автоконфиг

**Профиль**:
Сохранённый набор настроек, который можно применить к следующей карте. Пустой профиль означает запись образа без изменений.
_Избегать_: шаблон, пресет

**Рабочая копия**:
Временная копия образа, в которую кладут настройки; пишется на карту именно она, исходный файл не трогается.
_Избегать_: временный образ, клон

**Первая загрузка**:
Первое включение платы с карты, во время которого применяются настройки. Одноразовая: после неё плата настроек не помнит.
_Избегать_: первый запуск

**Мастер первого входа**:
Интерактивный диалог Armbian, который спрашивает пароль и пользователя при первом входе. Если задан пользователь, он пропускается.
_Избегать_: мастер настройки, firstlogin

**Классический ext4**:
Файловая система образов Wukong без `64bit` и `metadata_csum`. Только такую умеет изменять программа.
_Избегать_: обычный ext4

**Drop-in**:
Файл `.conf` в каталоге `имя-службы.service.d`, который дополняет штатную службу systemd, не заменяя её.
_Избегать_: оверрайд, патч службы

**Каталог**:
Список производителей, плат и образов. Встроенный содержит плату без образов; внешний подключается одним полем.
_Избегать_: репозиторий, API

**Источник каталога**:
URL или папка на диске, где лежит файл каталога. Необязателен.
_Избегать_: сервер каталога

**Прошивка**:
Запись образа на карту с последующей побайтовой проверкой.
_Избегать_: флеш, запись образа
