## Что должно заработать

Выбрав образ и карту, пользователь заполняет настройки в существующем мастере профилей: сеть, пользователя, SSH, регион, устройство. Может сохранить профиль и применить к следующей карте. На экране подтверждения видна сводка и предупреждения. Если образ не поддерживает настройки, видно почему, и запись остаётся доступной.

## Критерии приёмки

- [ ] Для образа Wukong блок настроек виден; для `.iso` без ext4 и прочих неподдерживаемых — отключён, с текстом по каждому `ImageSupport`
- [ ] Мастер и редактор содержат: имя устройства (предложено `wukong`), Wi-Fi с флагом «скрытая» и страной, статический IP, пользователь, пароль root, SSH (вкл, вход по паролю, вход root, ключи, импорт GitHub), часовой пояс, локаль, раскладка, оверлеи, свой скрипт
- [ ] Валидация логина, имени устройства, длины Wi-Fi-пароля, скрипта до 64 КБ; ошибки у полей, введённое не теряется
- [ ] Блокирующая ошибка, если вход по паролю выключен и ключей нет
- [ ] В `settings.json` нет открытых паролей: проверяется просмотром файла после сохранения; пустое поле при существующем хеше сохраняет хеш; смена SSID требует ввода пароля заново
- [ ] Экран подтверждения показывает диск, размер, сводку и предупреждение root/1234, если пользователь не задан и включены Wi-Fi или SSH
- [ ] После записи показана подсказка, как подключиться (`ssh user@имя.local` или IP)
- [ ] Все новые строки есть в `en.json` и `ru.json`; `npm run lint` и `npm run build` чисты
