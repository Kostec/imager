# 03 — Настройки ложатся на карту и применяются при первой загрузке

**Требования:** R06, R07, R08, R11, R12, R13, R24i, R25i, R26i, G01, G02, G07, G08
**Зависит от:** 01, 02
**Зона:** `src-tauri/src/provision/` · `src-tauri/device/` · `src-tauri/src/autoconfig.rs` · `src-tauri/src/commands/operations.rs` · `src-tauri/src/commands/custom_image.rs` · `src-tauri/src/ssh_keys.rs`
**Волна:** 2
**Ревью:** да — пароли и секреты
**Модель:** сильная

## Что должно заработать

Backend получает настройки, хеширует секреты, проверяет образ, кладёт на рабочую копию скрипты и файл настроек. На первой загрузке плата применяет их до приглашения входа, затем затирает всё за собой. Пустые настройки не меняют образ ни на байт.

## Из брифа, дословно

> «После запуска с прошитой SD карты устройство должно запуститься с указанными настройками. Т.е. если был указан Wifi, то устройство должно к нему подключиться, если указаны настройки SSH, то SSH должен работать»
> «при первом запуске все настройки уже были применены»

## Критерии приёмки

- [ ] `AutoconfigConfig` в Rust — поля из `interfaces.md` §3; `Debug` не показывает значения
- [ ] `hash_password` даёт `$6$`, проверяемый `openssl passwd` или `crypt`; `derive_wifi_psk` проходит тестовый вектор IEEE 802.11i
- [ ] `render_bundle` экранирует одинарную кавычку, `$`, переводы строк, кириллицу в SSID; исходные пароли не появляются ни в одном файле
- [ ] `probe_image` различает все варианты `ImageSupport` (включая `AlreadyBooted` по отсутствию симлинка в `multi-user.target.wants`)
- [ ] `prepare_flash_copy` вызывает `provision_image`; при `is_empty` рабочая копия не создаётся и пишется исходный образ
- [ ] `firstboot.sh` выполняет всё из историй 9–31, 34 на этапе до сети, идемпотентен, не падает при ошибке шага, каждый шаг пишет итог в `/var/log/wukong-firstboot.log` без секретов
- [ ] `post-network.sh`: ожидание сети до 120 с и `chrony`, установка `avahi-daemon` при заданном имени, свой скрипт с таймаутом 5 минут, самоудаление
- [ ] После первой загрузки `firstboot.conf`, скрипты и drop-in перезаписаны и удалены, служба `post-network` отключена
- [ ] Ethernet не отключается при Wi-Fi; `ssh` маскируется при запрете; автологин снимается только при заданном пользователе
- [ ] `bash -n` и `shellcheck` чисты; прогон `firstboot.sh` в Docker на распакованном rootfs образа (arm32 через qemu-user или с заглушками `systemctl`/`nmcli`) подтверждает файлы результата
- [ ] Новые команды Tauri `hash_password`, `derive_wifi_psk`, `probe_custom_image`, `fetch_ssh_keys` зарегистрированы; `examples/provision.rs` для e2e
