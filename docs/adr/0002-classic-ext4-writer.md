# ADR 0002. Свой писатель ext4 вместо `armbian-ext4fs`

Статус: принято.

## Контекст

Настройки должны попасть на карту с Windows, где нельзя смонтировать ext4. Upstream использует `crates/armbian-write-conf` на базе `armbian-ext4fs`. Для образов Wukong он не подходит: их ext4 классический (без `64bit` и `metadata_csum`), а в этом режиме библиотека паникует при `s_desc_size=0`, портит соседний дескриптор и ставит всем файлам режим 0777. Вставка в каталоги с htree (`/etc`, `/usr/lib`) отказывает. В release действует `panic=abort`, поэтому паника означает аварийное завершение посреди работы с образом.

Патч затронул бы пять с лишним файлов чужого кода, а любая ошибка в нём осталась бы тем же abort. При этом нужно мало: создать один небольшой каталог и положить в него несколько новых файлов с заданными режимами.

## Решение

Новый crate `crates/classic-ext4` (MIT): разбор MBR, суперблока и дескрипторов, аллокация, вставка записей каталога. Наружу не выходят блоки и inode, только `open`, `exists`, `is_regular_file`, `mkdir`, `write_new_file`, `commit`.

- Всё меняется в памяти, на диск идёт только в `commit`: ошибка до него не оставляет следов. `commit` не атомарен при сбое записи, поэтому он работает только с рабочей копией образа, а не с исходным файлом.
- Всё, что не поддержано, отвергается при открытии как `Unsupported`: блок не 4096, inode меньше 256, `metadata_csum`, `gdt_csum`, `64bit`, `needs_recovery`, `bigalloc`, `inline_data`, родитель с htree.
- На данных из образа нет `unwrap`, `expect` и `panic`, все ошибки возвращаются как `Result`.
- Файлы только новые и только `root:root`. Изменять существующие файлы писатель не умеет и не должен.

`crates/armbian-write-conf` не меняется: им по-прежнему пользуется ветка QDL.

## Последствия

- Образ с `metadata_csum` и другой ФС настройки не получит: программа заранее объясняет причину и может записать его без настроек. Для образов Wukong этого достаточно.
- Появился свой код, работающий с on-disk форматом. Его проверяет `e2fsck -fn` на фикстуре и на настоящем образе (`scripts/e2e/run.sh`).
- Писатель не умеет править большие каталоги, поэтому точка входа на плате выбрана так, чтобы это не понадобилось (ADR 0003).
