# ADR 0005. Собственный каталог образов вместо API Armbian

Статус: принято.

## Контекст

Каталог upstream целиком ходит на `api.armbian.com`: платы, образы, картинки, проверка связи. Если сервер недоступен, интерфейс переключается в офлайн-макет и сбрасывает выбор. Пользователю нужны только Wukong Pi Zero и, необязательно, свой источник образов: сервер в Docker или папка на диске. Первый запуск без интернета должен работать полностью.

## Решение

Встроенный каталог зашит в код и содержит производителя и плату, но ни одного образа: образ приходит из файла или внешнего каталога. Внешний источник задаётся одним необязательным полем: URL или путь к папке с файлом `catalog.json` версии 1. Формат свой и простой, в нём те же сущности, что уже знает интерфейс: производители, платы, образы. У образа либо `url`, либо `file` (путь внутри папки каталога, за её пределы не выходит), и `sha256`. Внешний каталог дополняет встроенный; ошибка внешнего не ломает встроенный, а показывает место ошибки. При встроенном каталоге программа всегда «онлайн», при URL проверяется сам URL.

## Почему

- Оставить Armbian API. Отвергнуто: это обращения к чужому серверу при каждом запуске, образы Wukong там не появятся, а недоступность сервера выключала бы интерфейс.
- Переопределить базовый адрес API и поднять совместимый сервер. Отвергнуто: пришлось бы реализовать чужой протокол с пагинацией, а `reqwest` не умеет читать локальную папку; картинки и логотипы в upstream вообще жёстко привязаны к `armbian.com` и адрес не меняют.
- Формат на основе типов ответов Armbian API. Частично принято: внутри берутся те же типы, поэтому остальной интерфейс не меняется, но внешне формат плоский, чтобы его можно было написать руками и отдать через nginx.
- Только URL или только папка. Отвергнуто: оба случая названы в требованиях, а различаются они лишь тем, откуда берутся байты, поэтому поле одно.
- Сервер каталога как часть проекта. Отвергнуто как избыточное: в репозитории только пример с nginx в Docker.

## Последствия

- Формат `catalog.json` теперь наш контракт: его версия записана в файле, менять его придётся совместимо.
- Образы из каталога без `sha256` не проверяются; контрольная сумма проверяется для каждого записанного, а при несовпадении файл удаляется и запись не начинается.
- Для образа из папки нужна отдельная ветка загрузки без HTTP, а проверка «путь не выходит из папки» ложится на нас.
- Фото платы и логотип производителя не тянутся из сети, вместо них нейтральный значок.
- Встроенный каталог без образов означает, что «из коробки» прошивка идёт только с файла на диске; удобный список появляется лишь после подключения своего источника.
- Другим производителям и платам место есть, но шаги выбора производителя и платы видны, только если их больше одного.
